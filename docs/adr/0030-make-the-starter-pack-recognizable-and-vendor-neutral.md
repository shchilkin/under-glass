# Make the starter pack recognizable and vendor-neutral

The optional starter pack uses original isometric infrastructure miniatures whose silhouettes remain recognizable without a label, while avoiding cloud-vendor logos and provider-specific replicas. Assets share a consistent scale, material language, grounding convention, detail budget, and Connection Port treatment. Their names are usage suggestions rather than built-in Node types: the host and label define meaning. This gives project diagrams immediate legibility without coupling the generic component to a cloud taxonomy.
