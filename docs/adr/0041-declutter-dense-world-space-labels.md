# Declutter dense world-space labels by presentation priority

The host or a future Editor owns authored Node, Group, and route positions, but the Viewer must remain readable when a camera pose or small viewport compresses those positions on screen. PopChoice presets therefore use explicit interior padding, aligned Node rows or columns, and visible gutters between Group regions. At render time the Viewer projects world-space label bounds into screen rectangles. At ordinary desktop widths Node and Group labels are protected while conflicting Connection captions yield. In genuinely compact containers deterministic progressive disclosure follows Node, Group, Connection priority. Portrait projections zoom out so the authored horizontal span is not cropped. Hidden visual labels remain in the semantic HTML overlay. This fallback does not mutate the Visualization, invent a new layout, or replace an Editor.
