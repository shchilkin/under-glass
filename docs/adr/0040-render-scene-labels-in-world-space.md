# Render visual labels in world space

Group names, Node names, and Connection captions all render as textured planes inside the 3D scene so they share its perspective and animate naturally between isometric and top cameras. Their roles remain distinct: Group names are quiet structural typography printed into regions, Node names are the primary high-contrast sans-serif layer beside each model, and Connection captions are compact monospace nameplates aligned to their longest route segment. Node and Connection labels use deterministic world-space collision resolution and camera-aware scale. The HTML overlay retains visually hidden text for every label type so accessibility does not depend on the WebGL surface. This remains a renderer concern rather than a new Visualization schema field.
