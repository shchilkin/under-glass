# Under Glass v0.1.0 — Architecture Diagram + Minimal Editor

Under Glass v0.1.0 proves a presentation-quality, host-owned 3D architecture
diagram and the smallest useful authoring loop.

## Included

- GLB-only host-resolved assets with a documented missing-asset Placeholder;
- differentiated 3D Nodes, world-space labels, and flat Group regions;
- basic deterministic directional Connections;
- canonical isometric and top Camera Modes;
- `responsive` and `spring` Camera Motion choices;
- selection and movement of existing Nodes;
- configurable Grid snapping and overlap rejection;
- one reversible Move Node Operation with session-local undo and redo;
- semantic HTML content when WebGL2 is unavailable;
- pinned Chromium visual baselines and repeated renderer teardown evidence.

## Deliberately deferred

v0.1 does not include Node or Group creation, Group editing, Connection
authoring, obstacle-aware routing, Route Anchors, Route Conflicts, a public
React Editor API, persistent history, real-time collaboration, or npm
publication.

All repository workspaces use the lockstep `0.1.0` version. The GitHub release
and `v0.1.0` tag are created only after the maintainer reviews and merges the
release pull request. No package is published to npm for this release.
